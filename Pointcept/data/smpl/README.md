The SMPL model and code are not part of this repository and remain subject to the SMPL license.
Register at [SMPL](https://smpl.is.tue.mpg.de/), download SMPL for Python (v1.1.0) and place its files under `Pointcept/data/smpl/` as below.

```
Pointcept/data/smpl/
├── models/                  # basicmodel_neutral_lbs_10_207_0_v1.1.0.pkl
└── code/
    ├── serialization.py
    ├── lbs.py
    ├── posemapper.py
    └── verts.py
```
