# ScanObjectNN

The ScanObjectNN dataset is not part of this repository and remains subject to the ScanObjectNN Terms of Use.
Agree to the terms at [ScanObjectNN](https://hkust-vgd.github.io/scanobjectnn/), download the raw `object_dataset.zip` and place its chair folder under `Pointcept/data/scanobjectnn/` as below.
Then run `preprocess.py` from this folder.

```
Pointcept/data/scanobjectnn/
└── chair/                   # from object_dataset.zip
```
